游戏文件解剖

《魔兽争霸III》的游戏数据存放在哪里、用什么格式、每个文件（夹）是干什么的？这页面向想改档、汉化、拆资源或写工具的玩家，按「档案格式 → 工具 → 目录 → 文件格式」的顺序过一遍。

两代档案格式：MPQ 与 CASC

游戏文件从不以散装文件形式躺在硬盘上，而是打包在档案（archive）里：

  • MPQ：1.31 之前的老档案格式。旧版安装目录下的 war3.mpq、war3x.mpq、war3patch.mpq、war3local.mpq、war3xlocal.mpq 都是 MPQ。
  • CASC（Core Asset Storage System）：1.32（重制版）起全面启用的新格式，取代 MPQ。所有资源统一存进一个 CASC 存储，不再按补丁拆包。

两代共同的顶层是 本地文件 > 地图包：往地图里导入的同名资源会盖掉游戏自带的。再往下才轮到游戏档案——MPQ 时代按 war3patch.mpq > war3xlocal.mpq > war3x.mpq > war3local.mpq > war3.mpq 逐层回退（补丁包级别最高，x 为冰封王座专用，local 为语言层；此外每张地图还会按地形额外加载一个地形包，如 A.mpq）；重制版把这些层压成一个 CASC 存储。这也是「启用本地文件」能覆盖游戏数据的原因，见文末。

工具：CASCView

CASC 格式社区通用的浏览、提取工具是 Ladik 的 CASCView（Ladislav Zezula，免费），旧版 MPQ 则用他家的 MPQ Editor。

  1. 下载并运行 CascView，菜单 Storage → Open Storage（打开存储）。
  2. 选择游戏根目录——即包含 .build.info 的那个文件夹（通常是 Warcraft III\_retail_\），程序会自动识别 CASC 存储。
  3. 左侧文件树展开 war3.w3mod 等节点，右键 Extract / Export 即可导出单个文件或整个目录。

两点提示：① 文件树里大量出现的 .w3mod 后缀只是虚拟目录标记，不是真实文件夹；② CascView 是只读工具，想改动请先导出，再走文末的本地文件覆盖流程。

核心数据文件：SLK 与 INI 串表

「单位/技能/物品/科技」的对象数据由三类纯文本文件拼合而成，改数据、做对照都绕不开它们：

SLK 表（数值字段）

units\ 与 _Balance\*.w3mod\units\ 下的 .slk 是类 SYLK 电子表格文本，一行形如 C;X列;Y行;K"值"，首列 ID 决定对象。常见文件：

  • UnitData.slk / UnitBalance.slk / UnitUI.slk / UnitWeapons.slk —— 单位数据（杂项 / 属性 / 界面 / 武器）
  • AbilityData.slk —— 技能数据
  • ItemData.slk —— 物品数据
  • UpgradeData.slk —— 科技升级
  • DestructableData.slk —— 可破坏物

*Func.txt（补充字段）

同目录下的 HumanUnitFunc.txt、CommonAbilityFunc.txt、ItemFunc.txt 这类文件是 INI 风格的补充字段：按钮位置、快捷键、图例引用等。

*Strings.txt（显示文本）

名称与提示文本集中在语言层 _locales\<语言>.w3mod\units\ 下（humanunitstrings.txt、commonabilitystrings.txt、itemstrings.txt……按种族 / 类别分文件），同样是 INI 格式，以对象 ID 为节：

[AHtb]                          ; 山丘之王 —— 风暴之锤（节选，有删改）
Name=风暴之锤
Tip=风暴之锤(|cffffcc00T|r)
Ubertip=掷出一把魔法之锤，对目标造成伤害并使其眩晕。

常用键：Name（名称）、Tip（按钮提示）、Ubertip（详细说明）、Hotkey、EditorSuffix；|cAARRGGBB…|r 是内联颜色标记。

本站汉化词条表与补丁说明的专名，就是拿 zhcn.w3mod 与 enus.w3mod 两套 Strings 逐 ID 对照核出来的。

ui\ 目录（编辑器与界面）

编辑器的行为数据在基础层 ui\：triggerdata.txt（触发 GUI 的事件 / 动作 / 参数结构）、triggerstrings.txt、worldeditdata.txt（菜单、对象编辑器字段等）、worldeditstrings.txt、aieditordata.txt 等；对应的显示文本在语言层 _locales\<语言>.w3mod\ui\。ui\framedef\ 与语言层 ui\framedef\*.fdf（如 globalstrings.fdf）则是游戏内界面的框架定义。编辑器汉化补丁改的主要就是这批文件。

地图文件（.w3m / .w3x / .w3n）

地图也是档案包：.w3m 是原版（混乱之治）地图，.w3x 是冰封王座地图，.w3n 是战役包——本质都是带 512 字节头部的 MPQ 容器。游戏本体虽已改用 CASC，地图至今仍是 MPQ，所以拆地图用 MPQEditor，不必碰 CASC。包内的 war3map.* 家族——地形 .w3e、地图信息 .w3i、物编七件套 .w3u / .w3t / .w3b / .w3d / .w3a / .w3h / .w3q、触发 .wtg / .wct、字符串表 .wts 等——逐文件详解见姊妹篇：

启用本地文件（Allow Local Files）

游戏默认只读地图和 CASC。开启「本地文件」后，读取顺序变为「本地文件 > 地图 > CASC 各层」——把文件按 CASC 内的有效路径放进游戏根目录，游戏就会优先加载你的文件。

注意本地文件整体只是最上面的一个「图层」，不能像 CASC 里的 _hd.w3mod、_locales 那样拆成多个层互相叠放覆盖。

第一步：修改注册表

在注册表 HKEY_CURRENT_USER\Software\Blizzard Entertainment\Warcraft III 下新建一个 DWORD (32 位) 值：名称 Allow Local Files，数值数据 1。三种做法任选其一：

  • 直接运行本站编辑器汉化补丁附带的 AllowLocalFiles.reg；
  • 自建 .reg 文件：新建文本文档，粘贴以下内容，另存为 allow.reg 后双击导入；
  • 命令行一条搞定：reg add "HKCU\Software\Blizzard Entertainment\Warcraft III" /v "Allow Local Files" /t REG_DWORD /d 1
Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Blizzard Entertainment\Warcraft III]
"Allow Local Files"=dword:00000001

关闭同理：把值改回 0 或删除该值即可。注意游戏根目录的位置：1.32.7 起是安装目录下的 _retail_\（PTR 为 _ptr_\），更早版本直接就是安装目录。

第二步：按有效路径放文件

把 CascView 导出的文件放进游戏根目录，路径 = CASC 虚拟路径去掉 war3.w3mod\、_locales\zhcn.w3mod\ 等层前缀后的有效路径：

  • war3.w3mod\units\human\peasant\peasant.mdx → _retail_\units\human\peasant\peasant.mdx（换农民模型）
  • _locales\zhcn.w3mod\ui\WorldEditStrings.txt → _retail_\ui\WorldEditStrings.txt（编辑器汉化补丁即由此生效）

两个典型玩法

  • 画面 MOD：把改好的纹理和模型按目录整包复制进 _retail_\ 的相应目录（units\、buildings\、textures\……），覆盖同名文件。
  • 字体 MOD：把字体文件放进 _retail_\ 的 fonts\ 目录，覆盖 war3.w3mod\fonts\ 同名文件。

风险：本地文件在联机时同样生效，改动可能被对战平台视为作弊，请勿在对战中使用。
