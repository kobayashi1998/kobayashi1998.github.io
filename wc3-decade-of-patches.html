1.27（a / b）1.27a：2016-03-15 · 1.27b：2016-12-13/142011 年以来首个补丁
时代背景：时隔 5 年（2011–2016）暴雪重启更新，先做系统兼容，为后续重制版铺路。
游戏功能性更新
  • 1.27a：支持 Windows 7 / 8.1 / 10；新增 Mac 10.10 / 10.11 安装器。
  • 1.27a：选项新增 1920×1080 分辨率（但无宽屏适配，画面拉伸）。
  • 1.27b：地图文件大小上限 8MB → 128MB（对自定义地图 / 战役是重大利好）。
地图编辑器更新
  • 1.27b：世界编辑器新增「Script Verify（脚本校验）」功能。
BUG 修复
  • 1.27a：修复闪电链（Chain Lightning）崩溃。
  • 1.27b：自定义 .blp 贴图文件不再导致 Mac 崩溃。
  • 已知问题：窗口化下伽马设置不生效、西里尔字符仍无法显示、Mac 不支持编辑器。
1.28（含 1.28.1–1.28.6）1.28：2017-04-05小修补丁系列
游戏功能性更新
  • 新增显示模式：窗口化全屏（默认）、窗口化（-window）、原生全屏（-nativefullscr）。
  • 窗口模式新增鼠标光标限制选项（仅游戏窗口内活动，菜单可解除）。
  • 数据迁移不再需以管理员身份运行即可访问游戏存档。
  • 优化安装与更新效率。
地图编辑器更新
  • 修复 WorldEdit 的 Map Script Validation 图标与词条。
BUG 修复
  • 修复 CommandFunc.txt 特殊坐标（0,-11）/（-2147483648,-2147483648）导致命令卡错误隐藏。
  • 修复比赛结束断战网、视频播放器任意分辨率播放、Windows GameDVR 失效。
  • 1.28.2：湿地地图重新加入地图池；Raise Dead 不再导致 Windows/Mac 跨平台反同步；编辑器 Test Map 写入临时目录。
1.292018-04-10（PTR：2018-02-21）经典时代最大补丁
里程碑：真正的宽屏、24 人游戏、以及编辑器上限与 natives 的爆发式扩容，是 Mod 社区的一次狂欢。
游戏功能性更新
  • 真宽屏：原生 16:9 宽屏支持，不再拉伸变形（界面加 bookends、菜单加黑柱防拉伸）。
  • 24 人游戏：大厅支持最多 24 名玩家；队伍颜色扩展。
  • 12 种新队伍颜色：Maroon / Navy / Turquoise / Violet / Wheat / Peach / Mint / Lavender / Coal / Snow / Emerald / Peanut。
  • 官方 Streamer/Caster API：可读取金币、木材、食物、APM 等观战信息（无需第三方破解）。
  • 英雄平衡：13 主族英雄 + 6 酒馆英雄调整；多数英雄移速 270→290；剑圣 / 恶魔猎手削弱，多个冷门英雄增强。
  • 地图池：1v1 / 2v2 / 3v3 / 4v4 / FFA 全部更新。
地图编辑器更新（爆发式扩容）
  • 对象上限 → 30,000（中立单位 2048、中立建筑 384、玩家单位 4320、玩家建筑 2400、物品 1024）。
  • 地图尺寸 → 480×480；瓦片上限 → 16。
  • 最大执行数 → 3,000,000；最大食物 → 999；最大资源 → 9,999,999；数组大小 8192 → 32768。
  • 90+ 新 natives：特效全控制（缩放 / 旋转 / 俯仰，替代假人单位做弹道 / 特效系统）、能力 / 物品 / 单位增强控制、鼠标悬停与点击响应。
BUG 修复
  • 战队可重新创建；Mac 客户端可启动；韩语区启动；多处缺失贴图定位；默认分辨率不再异常。
  • 已知问题：原生全屏无法改分辨率、XP 为最后支持版本、部分 natives 改名 / 暂时停用。
1.302018-08-08（含 1.30.1–1.30.4）平衡 + 底层迁移
游戏功能性更新
  • 升级反作弊系统。
  • 更新观战 API，可导出更多游戏信息。
  • 启用 Large Address Aware（部分机器最多使用 3GB 内存）。
  • 游戏文件由 MPQ 迁移至 CASC 文件系统。
  • 平衡：大法师 / 剑圣 / 巫妖 / 恶魔猎手 / 酒仙 / 深渊魔王等英雄，及火枪手 / 猎头者 / 死灵法师 / 女猎手 / 山岭巨人等单位大幅调整；大量中立 / 物品 / 地图池改动。
地图编辑器更新
  • 最多可选 16 瓦片（含悬崖）。
  • 新增 natives：BlzPlaySpecialEffect、BlzSpecialEffectAddSubAnimation、BlzSpecialEffectRemoveSubAnimation、BlzSpecialEffectClearSubAnimations；BlzSetSpecialEffectHeight 计入地形高度。
BUG 修复
  • 修复自定义能力目标参数崩溃、网络延迟恢复、原生全屏鼠标、带弹幕升级的攻城坦克占用 4 食物等。
1.312019-05-28（PTR：2019-04-24）Reforged 前最后经典补丁
里程碑：底层图形 API 现代化 + 编辑器支持 Lua，为 2020 年重制版铺路。
游戏功能性更新
  • 集成 Direct3D 11 与 Metal 图形 API；Windows / Mac 支持 64 位（Mac 弃用 32 位）。
  • 客户端非激活时关闭声音；扩展窗口模式。
  • RoC 关闭战网（混沌之治玩家自动获得冰封王座）。
  • 大量平衡 + 地图池更新（约 30 张地图）。
地图编辑器更新（面向重制版）
  • Lua 脚本支持（Beta）：地图可选 JASS 或 Lua（Scenario → Map Options → Script Language）。
  • 对象修改系统 API：运行时修改物品 / 能力 / 单位等。
  • 地图以文件夹保存（以及 MPQ），结构可在编辑器外更新，利于多人协作开发。
  • 地图松散文件自动导入。
  • UI 编辑器、官方战役地图可在编辑器打开；256 骨骼支持。
BUG 修复
  • 修复触发器保存丢失、自定义电影播放、多个地图反同步（DBZ / Builders and Fighters 等）、声音数据跨图传输、占有命令残留、OBS 切窗冻结、观察者全局战斗音效等。
1.32（Reforged 发布）2020-01-28（含 1.32.1–1.32.10 修复期）重制版上线
里程碑：《魔兽争霸III：重制版》正式发布，全面翻新画面与战役，但上线初期口碑受挫；1.32.1–1.32.10 为后续两年持续修复期。
游戏功能性更新
  • 重制画面：全部英雄 / 单位 / 建筑 / 环境高清重制；支持经典 / 重制双模式切换。
  • 战役重做：恢复 3 个原版 Demo 序章任务（Riders on the Storm 等）；全部任务更新地形 / 难度并加入自动存档；达拉然 / 银月城 / 斯坦索姆三城美术与布局重制。
  • 收藏系统：英雄皮肤、头像、可解锁的战役与匹配奖励。
  • 语言：新增西班牙语（拉美）、葡萄牙语（巴西），并更新简体 / 繁体中文等 9 种语言。
  • 战网集成：从战网客户端安装 / 更新 / 启动，含群组与聊天；经典账号链接（保留历史战绩，90 天期限）。
  • 匹配系统：1v1 / 2v2 / 3v3 / 4v4 / FFA 竞技匹配；可组队 2v2 / 3v3 / 4v4。
  • 热键与设置：新增 Grid / 传统热键布局；血条 / 队伍颜色 / 英雄状态条 / 冷却显示设置。
地图编辑器更新
  • 1.32 本身编辑器改动有限；1.32.x 修复期持续修复编辑器与自定义地图相关问题（JassHelper 不关闭、部分重制中立单位不可见等）。
BUG 修复 / 已知问题
  • 上线初期大量已知问题：加载黑屏、古树根须放置图标缺失、自定义地图 >256MB 破坏大厅、非拉丁字符重叠、非美式键盘键位失效、跨平台无法邀请、编辑器 JassHelper 残留等，均在 1.32.x 逐步修复。
1.33.02022-08-17 上线（官方标注 8-10）排名系统
核心亮点：排名对战、玩家档案、排行榜三大系统，以及镜头缩放功能。

编辑器更新
  • 世界编辑器启用 Windows 10 通用控件；GPU 渲染器更新（字体渲染变化，-legacykerning 恢复旧字体）；旧版 Popcorn 特效错误提示。
