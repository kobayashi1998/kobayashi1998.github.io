一、第一幕：征服大地8 节

主图 1 张 + 子图 4 张。出生点周围集中了第一幕全部补给，出发前先把八家店逛一遍。

1.临终托付

  • 信使莫戈林被野猪人围杀，清怪，把报告送进奥格瑞玛交给萨尔。
  • 往东先认一眼复活石，以后死在这一带从这儿爬起来。
  • 出生点周围八家店，各有分工：
    • 奥格瑞玛军械库——第一幕唯一的换装点：四件属性装（护手、鞋、斗篷、头环）与四把武器。
    • 战争磨坊——两把近战、两把远程与四件护甲。
    • 尼洛克的前哨站、地精货仓——戒指、卷轴、药水，另有几件图腾与法杖。
    • 艾西拉的市集——隐形与明澈药水、生命石与魔法石；雷酒要等陈的怪酒做到那一步才上架。
    • 巫毒小屋——书店：经验之书、重修之书、三属性之书、知识之书。
    • 穆普——被遗忘者四件套，整套卖。
    • 伐木机尊享版v800——伐木机左臂与工程护目镜三档。
  • 第一幕手头很紧，书店先别进：装备优先，书全指望任务发。

2.立稳脚跟（三选三，建议一次清完）

①封死隧道（加兹鲁维）

  • 子图：奥格瑞玛地道。护送 4 个地精工兵，炸掉西北、东北、东南三根支撑柱。
  • 工兵死一个门口补一个；英雄倒下在入口复活石起。
  • 顺路有地精商店，第一幕最便宜的一家。
  • 奖励：符文护手 + 奥术卷轴 + 一本天赋之书。护手拿到先拖进装备槽。

②雷霆草药（德雷克塔尔）

  • 子图：雷霆山。采齐微光草。
  • 笼子里关着兽人萨满，砸开笼子他会入队帮打。
  • 顺路地精商店，只卖药水、治疗卷轴与药膏——别指望在这张图换装。
  • 奖励：附魔小瓶 + 一本天赋之书。
  • 此图野点密集，后面还要回来——雷霆蜥蜴与凤凰蛋都在这条线上。

③鹰身女妖之患（纳兹格雷尔）

  • 杀鹰身女妖首领血羽。她会飞，是本作第一次「对空分工」：雷克萨风暴之锤点、洛坎妖术与毒蛇、米莎顶地面小怪。前期没有对空转远程的副手，对空只能靠技能与远程普攻。
  • 固定掉落：血羽之心（史诗饰品）。
  • 交任务后军械库上架三件标价 0 的奖励件，但只能挑一件——买走任一件，另外两件当场下架。这是第一幕最重要的选装决策：
    • 火拳护手（史诗手套，攻速）
    • 折刃护甲（稀有胸甲，带全队护甲光环）
    • 奥金护盾（精良副手，纯护甲）
  • 判断只看队伍缺什么：缺前排拿火拳，缺全队减伤拿折刃，缺副手槽拿奥金。

3.陈的怪酒（越早越好）

  • 陈在主图正中偏上、血羽巢上方魔法泉附近，头顶没有感叹号。
  • 三样材料：雷霆花鳞茎（左上）、一桶雷酒（右侧艾西拉市集，任务做到这步才上架）、雷霆凤凰蛋（右上，打雷霆凤凰）。
  • 凤凰会秒人：洛坎变形、米莎顶脸，别让陈自己上。
  • 凤凰倒下除了掉蛋，还掉 凤凰印记（精良饰品，主动技是一口锥形火焰），顺手捡走。
  • 完成：陈入队，自带一桶麦酒（精良副手，回蓝续航的底子）、城镇传送卷轴、微光烤肉，另有两本天赋之书。
  • 一桶麦酒是装备不是道具，要拖进副手槽才生效。

4.术士密会（隐藏支线）

  • 触发：主图左上角野猪人隧道尽头，走进死胡同即触发。
  • 救出被控制的兽人萨满摩根·狼歌，杀掉背叛的术士。
  • 奖励：萨满利爪（史诗主手）与古老圣物（任务奖励，摩根尸体旁），另有一件随机装备；收尾处还会给一本天赋之书。
  • 这一带还能捡到发条企鹅（史诗饰品，纯玩具，占格子，卖掉换钱）。

5.边境侦察 → 保卫边境

  • 先找瞭望哨的加尔索克，穿过兽穴到观星台，回萨尔交任务。
  • 兽穴顺路清野猪人（可选支线）：这张子图就是主线去观星台必经的地下岩洞，全图野猪人清完即可，不用单跑。全作经验与金币最肥的一图，别漏角落。此图无商店。
  • 东北海岸人类营地：先杀牧师（不杀就是无限奶），再处理步枪兵，狮鹫交给雷克萨风暴之锤。
  • 营地首领本尼迪克中尉固定掉落：荣誉护盾（史诗副手，带全队攻击光环）。全队第一件能用的团队光环副手，凯恩与雷克萨都吃得到。

6.再探雷霆山（主线后续，别漏）

  • 萨尔让你和德雷克塔尔查雷霆蜥蜴发狂的原因，真相是人类伐木营砍秃了林地。
  • 这一趟三件重头：
    • 雷蜥钻石（史诗饰品，带主动闪电链）——雷霆蜥蜴掉。
    • 德雷克塔尔的法术书（传说副手）——三颗雷霆蜥蜴蛋都收齐时给，全作最容易到手的一件传说。
    • 雷纹宝珠（饰品）——把发狂的雷霆蜥蜴清完给。
  • 这张图没有专属首领，别为传说件反复刷。巨人力量腰带、法师长袍、贵族头环都是第二幕的店货，这儿打不到。

7.警告巨魔 + 击退舰队（回音群岛）

  • 劝沃金撤退；过程中变成灵魂飞龙 / 蝙蝠骑士，击沉库尔提拉斯战舰。
  • 五处篝火，最后一处由海巨人守着。陈火焰之息 + 雷克萨风暴之锤最稳。
  • 这一图两家店，卖的几乎全是消耗品：地精商店（治疗 / 法力 / 隐形 / 明澈药水，另有生命石与魔法石）、巫毒小屋（强效药水、无敌药水，另有野性护符与暗矛之印）。换装只能靠野点。
  • 野点里有一件硬货：死亡领主之冠（传说头盔）——深海领主亡魂必掉。
  • 符文护腕（稀有手套）不从这张图掉，第二幕的塞拉摩市集与地精集市有售。
  • 沃金和他的族人在这张图与后续两幕反复出场。

8.悬崖会谈（第一幕收尾）

  • 萨尔收到「人类使节求和」信，约在奥格瑞玛东南悬崖，伏兵是冲萨尔来的抓捕队。
  • 打完从暗矛新村落坐飞艇去塞拉摩。出发前把药补满：飞艇落地就是第二幕，第一幕的店回不去了。

二、第二幕：旧日的仇恨9 节

大地图 + 9 张子图。主线一路推，支线插在刚能进的时候。

9.海滨基地

  • 落地找剑圣萨穆罗。人类船坞安放不稳定药水 → 趁乱进岛见吉安娜。
  • 贴阴影走，别引巡逻队；桶摆完引爆，炮位一乱就冲传送点。
  • 这一段是萨穆罗的单独戏份，雷克萨一行被移交、无敌且钉在待机点，操控的只有萨穆罗；他身上捡的东西离场时会被统一丢在吉安娜会面点，别指望带走。
  • 支线·血喙之怒：开图不到半分钟任务栏就会挂上这条——萨穆罗的私仇，大地图北侧杀狂暴的血喙。固定掉沉默法杖，顺手做掉。
  • 店 地精图书馆：经验之书、重修之书、三属性之书、知识之书——第二幕的书全在这儿。药水与保命件回主图的巫毒大厅买。

10.塞拉摩岛（人类幸存者 + 逃离）

  • 进纳迦巢穴救出被围的人类残兵，拿到「是戴林的人」的铁证。
  • 守关是纳迦海巫 / 女祭司法系：洛坎先变形，雷克萨点飞蛇。
  • 逃：抢运输舰 → 砸港口闸门（先点牧师和炮塔）→ 驾船出海。
  • 这一图四家店，是第二幕最富的补给点：希德的特价药水商店（药水与恢复卷轴）、魔杖法杖专卖店（四把法杖 + 四把魔杖，天裔法杖就在这儿）、塞拉摩市集（腰带、靴、长袍、头冠、护手、护腕等属性装），还有一家只卖四色宝珠（火焰 / 冰霜 / 闪电 / 毒液）。

11.莫高雷：鹰身女妖偷猎者 + 科多偷猎者

  • 先找凯恩：儿子贝恩被半人马掳走。
  • 两条声望支线，不做也卡不住主线，清完凯恩态度直接转。
  • 店 地精集市：腰带、靴、长袍、头冠、护手、护腕，外加生命宝石与法力垂饰——中段属性装一整套。
  • 掉落以皮甲、回血石与随机装备为主；这张图不卖书，别为买书绕路。

12.救贝恩，凯恩入队

  • 出村往南，先遇流亡的白牛头人，灵魂行者波文·风之图腾入队（能复活倒下的牛头人）。
  • 一路推半人马营，尽头打半人马首领凯拉格。他带随从，别一次全拉；陈踩地板、凯恩践踏控场。
  • 打死救出贝恩，还得原路扛回去：洞穴会再刷半人马，路口有落石堵路。
  • 贝恩交回 → 凯恩·血蹄入队。他等级低，后面四张刷怪图要带他一起刷。

13.尘泥沼泽：石槌食人魔 + 双试炼

  • 飞艇西南角下，找督军考戈尔。
  • 力量试炼：东边死亡擂台，清怪到底。通关给 好战头盔（史诗头盔）。
  • 鲜血试炼：单挑考戈尔，禁用所有道具（装备与天赋照常生效）。
    • 取巧：把闸门引开，放雷霆蜥蜴 / 野怪进来咬他；场上有回血符文与加速符文。
    • 决斗前装备与消耗品会被收走交给保管人，打完原样交还，放心带东西进去。
  • 赢下当上新督军，食人魔军团归你，天界灵魂宝珠（传说饰品）是完成奖励。
  • 店 魔法商店：药水、四种卷轴，另有食人魔三件——战棍、法师图腾、法师护腕。

14.格拉格特可汗（可选）

  • 大地图偏西，科卡尔半人马营地，笼子里关着兽人奴隶。
  • 打通营地、杀格拉格特可汗、救奴隶。涨声望，不影响主线。

16.杜隆塔尔的旗帜（可选任务，奖励别漏）

  • 这条不是一开局就能接：得等 ⑬ 双试炼交完、先血之役的任务挂上之后，回奥格瑞玛找萨尔才会接下。
  • 先回奥格瑞玛找萨尔说话：萨尔会委托你凑三样材料，这段对话结束，狂潮湾路口的封锁才撤（守卫让开、入口的弹回区失效）。
  • 三样材料的野怪——野枭兽、风暴之主、青铜龙——都是这段过场结束后才刷出来的，提前跑到位置上只有空地；任务一挂上，小地图会把三处一并标出来。
  • 青铜龙（三只里最硬，满编再去）：除青铜龙鳞外，还掉 法术免疫项链（传说饰品）。
  • 大地图东侧另有隐藏死亡领主（两只闪电亡魂守着，走浅滩过去）：掉 死亡领主之盾（传说副手）。它常驻在地图上，与军旗无关，早去晚去都行。
  • 材料凑齐再进狂潮湾：靠近萨尔，他当场授旗、封你为部落勇士，奥格瑞玛战旗直接进雷克萨背包（传说饰品，三属性加成 + 近战英雄与周围友方近战单位攻击吸血）。
  • 三样没凑齐也能进湾，但授旗不会播，战旗就拿不到。

17.先血之役（狂潮湾，第二幕终战）

  • 人口上限 40，四族能造，但不是传统运营图。目标只有一个：拆掉戴林的前线城堡，城堡不回血，蹭一下都算。
  • 配队：牛头人 + 食人魔 + 狼骑 + 投石车。
  • 别硬冲主门（箭塔 + 狮鹫巢），走北侧侧门逐塔拔。
  • 凯恩震荡波拆箭塔、陈火焰之息清步兵、雷克萨点狮鹫、洛坎变形保命。
  • 三家店：维兹班的岛屿珍宝店（各槽中段件 + 两件传说）、部落商店（药水与恢复卷轴）、特价饰品店（生命石与魔法石、闪避护符、重生十字章）。

18.血海

  • 开场萨尔被戴林的战列舰堵在海岸，吉安娜传送来，说外岛有地精船坞。
  • 吉安娜的条件：别杀她的兵。这句就是胜负线。
  • 三阶段：夺外岛地精船坞（岸炮 + 水元素守着，英雄别挤一团吃溅射）→ 出无畏舰与护卫舰 → 击沉库尔提拉斯战列舰。
  • 打法：别一次引两艘以上；先点护航驱逐舰和空军，再围殴战列舰，主炮砸无畏舰极痛。
  • 击沉第 5 艘战列舰时给 暴风雄狮号角（传说副手，全队护甲光环）——打满五艘才有，别提前收工。
  • 店 地精商店：极效药水与保命件，另有两件大件——凯伦的逃脱匕首与冰龙颅骨盾。

19.塞拉摩攻城：最后的海军上将

  • 胜利：击杀海军上将戴林·普罗德摩尔。
  • 失败：拆掉任何一座塞拉摩守卫建筑（吉安娜的塔、房子、民房全算）。全战役唯一会让你重打的地方。
