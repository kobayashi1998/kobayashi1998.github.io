🛠️编辑器与工具6 个问题

YDWE 仅适用于游戏 1.27a 版本，重制版没有 YDWE 可以使用。
该启动器仅用于兼容打开老地图，且无人维护，不建议用来作图。
使用该启动器可能会缺失新版本的触发组件，以及编辑器组件的翻译。
新版本编辑器增加了新的触发器和原生函数，不太需要额外新内容了。
现在已经没有 return bug 和暴露在外的 game.dll 文件，能做的新功能较少。

🧊模型与图标3 个问题

原因：1.32 时期（2020 年 1 月 ~ 2022 年 10 月）社区制作的高清模型，粒子效果可能存在兼容问题，放进 1.33 之后的编辑器就会崩溃。
解决：编辑器左上角 文件 → 参数设置 → 综合 → 素材模式，选「经典」，再打开地图，高清模型不显示，也就不会崩了。
之后可以考虑用 Retera's Model Studio 去掉 / 替换 / 修复该模型的粒子效果，再重新导入。
亮图标命名为 BTN，暗图标命名为 DISBTN，格式为 DDS（如 BTN***.dds）。
亮图标放进 ReplaceableTextures\CommandButtons\，暗图标放进 ReplaceableTextures\CommandButtonsDisabled\。
具体可参考用 Ladik's Casc Viewer 查看游戏自带图标的存放方式。
模型是靠内部记录的一段路径文本来寻找对应纹理的。
蜂巢社区下载的模型，直接阅读附赠的 readme 即可。
其余模型可用 MDX Pather 查看模型内部引用的纹理路径，再按该路径导入贴图。

📝地图与文本1 个问题

重制版官方地图使用带地区标识的 wts 文件实现文本翻译。
物编修改的粉字文本在 wts 文件里没有对应翻译，所以游戏内不会显示。
可在素材（导入）管理器里找到这些 wts 文件。
若地图面向全球玩家，应在地图里写英文，并在 wts 文件里写对应翻译。
若仅面向简中玩家，在素材管理器删除所有 wts 文件，直接在地图写中文即可。
修改官方战役请参考重制版作图交流群 - 群文件 - 常见问题 -「重制版修改官方战役的两个技巧」。
